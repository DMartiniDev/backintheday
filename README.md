# BackInTheDay

Personal engineering blog.

## Tech Stack

- **Astro 4**: static site generation, content collections, file-based routing
- **Markdown*: post content with frontmatter metadata
- **Shiki*: syntax highlighting (github-dark theme, built into Astro)
- **JetBrains Mono*: monospace typography throughout

## Running locally

```bash
yarn install
yarn dev        # http://localhost:4321
yarn build      # output to ./dist
yarn preview    # preview the production build
```
